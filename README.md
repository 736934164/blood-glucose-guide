# 血糖高，三餐怎么吃？把这些小动作放进每天

面向中老年读者的高血糖生活饮食图文指南。

**[打开图文阅读版](https://736934164.github.io/blood-glucose-guide/)**

包含三餐搭配、喝汤、主食、水果、食品标签、外出吃饭、饭后活动、测血糖和低血糖应对；配有 12 张图（含餐盘动图）。手机和电脑均可阅读。

本文主要适用于糖尿病前期和 2 型糖尿病的成年人。孕期、1 型糖尿病、肾功能异常、明显消瘦或吞咽困难者，需要单独制定方案。具体份量、血糖目标和用药，按个人情况确定。
